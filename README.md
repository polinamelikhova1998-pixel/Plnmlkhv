# DERZKO. 3.0 — GitHub Pages

Обновление существующего сайта. Бегущая англоязычная полоса удалена, на заставке «ШОУ НАЧИНАЕТСЯ ЗДЕСЬ», добавлены дополнительные мягкие лучи и световая вспышка. Все разделы и адаптивная версия сохранены.

## Обновление с iPhone
1. Распакуйте ZIP в приложении «Файлы».
2. Откройте репозиторий `Plnmlkhv` → **Add file → Upload files**.
3. Выберите **четыре файла** из этой папки: `index.html`, `styles.css`, `script.js`, `README.md`. Не загружайте сам ZIP.
4. Нажмите **Commit changes** для ветки `main`. Существующие файлы с теми же именами будут заменены.
5. Через 1–3 минуты обновите сайт на прежнем адресе GitHub Pages. При необходимости откройте приватную вкладку.

## Примечания
- Заставка запускается при каждой загрузке страницы и имеет кнопку «Пропустить».
- Фотографии и реальные кейсы добавляются позже, только после согласования публикации.
- Контактная форма демонстрационная, автоматическая отправка не настроена.
