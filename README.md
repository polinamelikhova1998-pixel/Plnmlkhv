# DERZKO. 2.0 — GitHub Pages

Готовый статический сайт с кинематографической заставкой при **каждом открытии** страницы.

## Как обновить существующий сайт на GitHub с iPhone

1. Распакуйте ZIP в приложении «Файлы».
2. Откройте существующий репозиторий `Plnmlkhv` на GitHub.
3. Вкладка **Code** → **Add file** → **Upload files**.
4. Выберите **index.html**, **styles.css**, **script.js**, **README.md** из папки DERZKO_2_0 (не ZIP).
5. GitHub предложит заменить файлы с теми же именами. Подтвердите **Commit changes** в ветку `main`.
6. Через несколько минут обновите прежнюю ссылку GitHub Pages. Ссылка не меняется.

## Особенности
- Заставка ~4,3 секунды при каждом открытии; кнопка «Пропустить»; уважение настройки Reduced Motion.
- Эффекты света на CSS без тяжёлого видео.
- Все изображения проектов — абстрактные концепции, не клиентские кейсы.
- Форма контактов в демо-режиме. Для реальной отправки нужен рабочий email или сервис форм и политика конфиденциальности.
- Для будущих фото добавьте согласованные изображения и замените декоративные блоки в `index.html`/`styles.css`.

## Локальный просмотр
Откройте `index.html` в браузере.
