# DERZKO. — сайт event-агентства

Готовый статический адаптивный сайт: HTML + CSS + JavaScript. Без сборки и платных библиотек.

## Предпросмотр
Откройте `index.html` в браузере. Для публикации можно использовать GitHub Pages.

## Публикация на GitHub Pages
1. Войдите в GitHub и создайте новый **Public** репозиторий, например `derzko-site`.
2. Выберите **Add file → Upload files** и загрузите `index.html`, `styles.css`, `script.js` и папку `assets` (если используется). Файлы должны лежать в корне репозитория.
3. Нажмите **Commit changes**.
4. Откройте **Settings → Pages → Build and deployment**.
5. В **Source** выберите **Deploy from a branch**, затем **main** и **/(root)**, сохраните.
6. После публикации сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/derzko-site/` (обычно через несколько минут).

## Перед публичным запуском
- В `script.js` замените пустое значение `CONTACT_EMAIL` на реальный адрес агентства. Форма откроет почтовый клиент, а не отправит данные на сервер. Для полноценной формы потребуется backend/сервис форм.
- Добавьте действующую политику конфиденциальности и согласие на обработку персональных данных с учётом применимого законодательства.
- Замените демонстрационные визуальные концепции на согласованные и разрешённые к публикации материалы.
- Проверьте права на название DERZKO. и доступность домена.
- Замените тексты и контактные данные на утверждённые.

## Структура
- `index.html` — все разделы и содержание.
- `styles.css` — дизайн, адаптивность и анимации.
- `script.js` — мобильное меню, модальные окна, анимации, демо-форма.

Сайт использует Google Fonts (Manrope); при отсутствии интернета применяется системный шрифт.
