## Добавить фотографии позже

В `index.html` найдите `photo-placeholder` в блоке `#projects`. В каждый блок можно вставить `<img src="images/project-1.jpg" alt="Описание события">`; изображения положить в папку `images`. Для заполнения портфолио используйте только согласованные фотографии, без конфиденциальных логотипов, имён клиентов и узнаваемых материалов.

## Публикация

Загрузите **все 5 файлов** из архива в корень GitHub-репозитория с заменой существующих и нажмите Commit changes.

Контактная форма пока демонстрационная: адрес для отправки не указан.
