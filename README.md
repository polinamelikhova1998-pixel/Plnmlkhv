## Публикация

Загрузите в корень репозитория GitHub Pages все пять файлов с заменой одноимённых: `index.html`, `styles.css`, `script.js`, `stage-smoke.png`, `README.md`. После Commit changes откройте страницу с `?v=44`.

Форма контактов остаётся демонстрационной, автоматическая отправка не настроена. Перед публичным запуском добавьте контактный адрес, политику обработки персональных данных и реальный обработчик формы. Концептуальные постеры не являются кейсами клиентов.
